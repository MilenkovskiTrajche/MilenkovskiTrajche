### 🏨 PAPARAZZI Luxury Apartments — [paparazziluxury.com](https://paparazziluxury.com)

> **Designed, built and hosted by me**, end to end — for a real boutique property in Bitola.

A multilingual (**[EN](https://paparazziluxury.com/en) · [MK](https://paparazziluxury.com/mk) · [DE](https://paparazziluxury.com/de)**) website for a traditional Bitola house renewed as nine individually styled rooms and apartments.

- ⚡ **Next.js + React + TypeScript**, deployed on **Cloudflare**
- 🖼️ Pre-generated **AVIF / WebP** image variants for fast, sharp photography
- 🗂️ Content as structured, typed data (rooms, amenities, FAQ, attractions) — no CMS, no database, nothing to break
- 🔒 Strict CSP, security headers and HSTS out of the box
- 🌗 Light / dark theme, mobile-first

### 🍽️ Restaurant POS Platform &nbsp;`🔒 private · in development`

A commercial point-of-sale platform for restaurants, cafés and bars, starting in North Macedonia.

- 🧠 **Offline-first by design** — a Local Server at each venue is the operational authority; checkout never waits on the internet
- 🧱 **.NET 10 modular monolith** with independent Local Server and Cloud hosts
- 🐘 **PostgreSQL** module ownership, reviewed **OpenAPI** contracts, integration + browser journey tests
- ⚛️ **React / Vite** local POS client
